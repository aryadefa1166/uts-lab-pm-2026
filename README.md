## Informasi Aplikasi
- **Nama Aplikasi:** Kuis UTS Mobile
- **Deskripsi Singkat:** Aplikasi kuis pilihan ganda interaktif berbasis Flutter di mana pengguna dapat memasukkan nama, menjawab serangkaian pertanyaan, dan melihat skor akhir.
- **Fitur-fitur yang Tersedia:**
    - Halaman *Welcome* dengan input nama pengguna dan validasi.
    - Halaman Kuis dengan indikator warna jawaban secara *real-time* (Hijau untuk benar, Merah untuk salah).
    - *State Management* untuk menjaga progres kuis agar tidak hilang atau *reset* saat perangkat dirotasi.
    - Halaman Skor Akhir yang menampilkan total nilai dan opsi untuk bermain kembali.
    - **[Fitur Tambahan]** Dukungan *Dual-Theme* (Light Mode & Dark Mode) otomatis.
    - **[Fitur Tambahan]** *Adaptive & Responsive Design* untuk mencegah *overflow* pada berbagai ukuran layar (Mobile, Tablet, Web View).
